# TalorianTP

Аддон для **WoW 3.3.5a**, автоматизирующий работу со спутником-помощником и ускоряющий доступ к подземельям, рейдам и игровым сервисам.

## Основные возможности

- **Управление спутником-помощником:**
  - Автоматический призыв спутника при включении аддона с проверкой боя, транспорта, невидимости и принадлежности юнита игроку.
  - Автоматическая установка и поддержание рейд-метки над призванным спутником.
  - При отключении аддона уже призванный спутник остается рядом и не отзывается принудительно.
- **Режимы диалога и автонавигация:**
  - Быстрое переключение рабочих режимов: *Телепорт*, *Баффер*, *Банк*, *Магазин/Ремонт*, *Аукцион*.
  - Автоматический проход по нужным пунктам диалогового меню, подтверждение стандартных всплывающих окон и ведение журнала последних меню (`/ttp gossip`).
- **База рейдов, подземелий и столиц:**
  - Полный каталог рейдов (23) и подземелий (52: Classic, TBC, WotLK), а также столиц с фильтрацией по фракции и расе персонажа.
  - Быстрый поиск с поддержкой кириллицы, выбор нужной сложности, отображение активных рейдовых сохранений (КД), кнопки быстрого перехода к актуальным рейдам и сброса КД.
- **Аналитика прогресса по инстам:**
  - Отображение на карточках инстов и кнопках сложности процента освоения и количества оставшихся предметов (при подключенном модуле анализа прогрессии).
  - Команда `/ttp rec` для быстрого вывода рейтинга лучших подземелий и рейдов в чат.
- **Макросы, клавиши, аукцион и интерфейс:**
  - Генерация персональных макросов под ключевые рейды, призыв и баффы.
  - Назначение клавиш и кнопок мыши через встроенное окно перехвата (`Bindings.xml`).
  - Перетаскиваемая кнопка на миникарте, информативное окно уведомлений и вспомогательная панель на аукционе.

## Скачать и установить (Releases)

1. Откройте страницу последнего релиза: https://github.com/Soodoqie/TalorianTP/releases/latest
2. Скачайте готовый архив **`TalorianTP-v*.zip`** из раздела **Assets** (внутри уже лежит готовая папка `TalorianTP/`).
3. Распакуйте содержимое архива в `<ПУТЬ_К_WOW>\Interface\AddOns\`.
4. Перезапустите клиент или выполните `/reload` в игре.

Либо клонируйте напрямую через Git:

```powershell
cd "<ПУТЬ_К_WOW>\Interface\AddOns"
git clone https://github.com/Soodoqie/TalorianTP.git TalorianTP
```

## Слэш-команды

- `/ttp` или `/talorian` — открыть окно аддона
- `/ttp summon` — проверить и призвать спутника
- `/ttp mark` — поставить метку на спутника
- `/ttp minimap` — показать кнопку у миникарты
- `/ttp rec` — показать топ инстов по оставшимся предметам/ковке
- `/ttp parse` — открыть окно анализа и сводку в чат
- `/ttp gossip` — показать последние перехваченные пункты диалога
- `/ttp auc` / `/ttp aucreset` — переключить или сбросить панель аукциона
- `/ttp status` — текущий статус аддона

## Выпуск новых релизов

1. Обновите `## Version` в [TalorianTP.toc](./TalorianTP.toc) и добавьте запись в [CHANGELOG.md](./CHANGELOG.md).
2. Закоммитьте и отправьте изменения в `main`.
3. Создайте тег и отправьте его на GitHub (`git tag v4.3 && git push origin v4.3`), либо создайте релиз через `gh release create` — workflow [release.yml](./.github/workflows/release.yml) проверит синтаксис/кодировку и прикрепит готовый архив `TalorianTP-<tag>.zip` к релизу.
