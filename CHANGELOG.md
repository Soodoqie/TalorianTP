# История изменений TalorianTP

## [v4.2] - 2026-11-27

- Базовый публичный релиз `TalorianTP` (`v4.2`) для WoW Prime (3.3.5a).
- Призыв спутника Талориана, авто-назначение рейд-метки и работа с миникартой (включая интеграцию с `PrimeHub`).
- Отключение аддона сохраняет уже призванного Талориана без принудительного отзыва.
- Поддержка назначения клавиш (`Bindings.xml`, включая захват `BUTTON3`) и интеграция с `AttuneParser`.
